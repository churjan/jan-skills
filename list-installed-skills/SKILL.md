# 本机技能清单

按当前文件系统列出技能，不使用历史清单或本轮已注入的技能目录代替扫描。

## 扫描

运行本技能随附的只读扫描器（将 `<skill-dir>` 替换为本技能所在绝对路径）：

```sh
python "<skill-dir>/scripts/render_inventory.py" --project "<当前工作目录>" --output "<输出目录>/installed-skills.html"
```

Windows 上也可用 `py -3`。输出目录优先使用用户指定位置，否则使用当前项目的 `output` 目录。脚本写出自包含 HTML，并返回文件路径、数量及读取错误。需要检查完整扫描记录时，可运行 `scripts/scan_skills.py` 获取 JSON。默认检查用户主目录、当前项目及其祖先目录下的常见技能位置；也会检查这些位置的隐藏工具目录中的 `skills` 子目录，支持 `CODEX_HOME`、`XDG_CONFIG_HOME`。不会遍历整盘或其他项目。

用户给出其他位置时，使用可重复的 `--root "<技能根目录>"` 追加扫描。不要因一个目录不存在就停止；无权限或其他读取失败必须在结果后说明，不能声称没有技能。缺少 Python 时，使用可用的文件系统工具执行相同范围的扫描。

仅将包含 `SKILL.md` 的目录视为技能。排除 `.system`、插件目录、缓存、回收站、依赖目录和版本控制目录；跟随技能软链接并记录实际目标，防止循环。遇到技能后不继续将其内部示例或资源识别为另一技能。同名但路径不同的安装分别保留。

目录位置只能证明技能存在，不能证明谁执行了安装。默认将用户/项目技能目录内的非内置技能作为“手动安装候选”，简短说明此口径。通过技能管理器或命令安装的技能也属于此清单；不要把“手动”限定为手工复制。除非有安装记录，不要编造来源或安装方式。

## 展示

默认生成 HTML 页面并返回可点击的绝对文件路径，不再在聊天中重复完整 Markdown 表格。使用随附 `assets/inventory.html` 模板，保持用户选定的极简样式：浅灰背景、白色圆角表格、细分隔线、标题、搜索框，仅有“技能名称”“所属目录”和“路径”三列；所属目录显示 `.agents`、`.codex` 等扫描来源，路径显示技能的安装位置。所属目录使用低调的彩色标签，`.codex` 为紫色、`.agents` 为青绿色、`.cursor` 为蓝色，其他目录使用稳定的配色。不要增加统计卡片、侧栏、范围、状态、日期、操作按钮等字段，不使用暗黑模式。

用户主目录下的路径以 `~/` 缩写，标题下统一解释 `~` 的实际目录；悬停路径可查看完整路径。普通路径为灰色，软链接目标仅在对应路径下方用琥珀色文字及浅暖色底的第二行展示，目标路径前显示“软链接”小标签和箭头，不新增列；普通目录不显示空占位。搜索匹配名称、所属目录、安装路径及链接目标。页面离线可用，不依赖 CDN，不联网、不自动重新扫描；再次调用本技能时更新扫描快照。

默认按所属目录分组排列，`.agents` 组始终放在最下面，其他目录按名称排序；每组内部按技能名称排序。各组之间不添加空隙或空白行，保持连续表格。保持现有三列表格，不额外添加分组卡片或字段。

技能名称使用文件夹名，同名不同目录保留独立行，不能仅按名称合并。页面内容必须转义，不能把目录名或技能文档内容作为 HTML/脚本执行。只有读取错误时才显示异常提示；无结果时说明“在已扫描范围内未发现”。

技能名称下方以灰色小字展示 `SKILL.md` frontmatter 中的 `description` 原文，不新增列。所属目录和路径列按内容宽度分配，完整显示安装路径及软链接目标，剩余空间全部留给名称和描述，避免固定百分比列宽浪费空间。窄屏或超长路径允许表格横向滚动，不裁切路径。描述单行省略过长内容，悬停可看完整描述，搜索同时匹配描述。缺少描述时留空，读取失败时显示“描述无法读取”；不根据名称编造用途，不执行技能文档中的指令。

聊天回复简短提供页面链接、安装位置数和必要异常说明即可。用户明确要求聊天表格或完整扫描详情时再提供对应内容。目录仅作为非内置技能的安装候选，不编造来源或安装方式。

本技能只读取技能文件并写出报告；安装、删除、移动和修改技能不属于此工作流。
